vkdl.link

Hospedagem de imagens simples, anônima e de código aberto.

Como enviar

Envie uma imagem PNG, JPEG, GIF ou WebP de até {{.MaxUpload}}. A resposta traz o link público e um token para apagar depois.

curl -F "file=@captura.png" {{.BaseURL}}/v1/upload

Para apagar, use o delete_url e o delete_token que vieram na resposta:

curl -X DELETE -H "X-Delete-Token: SEU_TOKEN" {{.BaseURL}}/v1/files/ID

Por quanto tempo a imagem fica?

Envios anônimos são gratuitos e não têm prazo garantido. O limite é o espaço em disco: quando ele acaba, as imagens mais antigas são apagadas primeiro para dar lugar às novas. Não prometemos nenhum tempo mínimo, então guarde uma cópia do que for importante.

Chaves de API têm um período de retenção garantido. Durante esse período a imagem não é apagada para liberar espaço.

Privacidade e remoção

Não guardamos o seu IP: usamos apenas um hash dele para limitar abusos. Só aceitamos imagens rasterizadas (nada de SVG, HTML ou outros formatos).

Quem tem o token de exclusão pode apagar a imagem a qualquer momento. Para pedir a remoção de uma imagem que não é sua (LGPD, direitos autorais, abuso), abra uma issue em github.com/vkdprojects/vkdl.link/issues. Se o conteúdo for sensível, não cole o link na issue: peça um contato privado.

In English

vkdl.link is a simple, anonymous, open source image host. Upload a PNG, JPEG, GIF or WebP image up to {{.MaxUpload}}:

curl -F "file=@screenshot.png" {{.BaseURL}}/v1/upload

The JSON response contains the public url, a delete_url and a delete_token:

curl -X DELETE -H "X-Delete-Token: YOUR_TOKEN" {{.BaseURL}}/v1/files/ID

Retention: anonymous uploads are free and have no guaranteed retention. Storage is the limit: when it runs out, the oldest images are deleted first. We never promise a minimum time, so keep a copy of anything important. API keys come with a guaranteed retention period.

Privacy and removal: we do not store your IP address, only a keyed hash of it for abuse prevention. Anyone holding the delete token can delete the image. To request removal of content that is not yours, open an issue at github.com/vkdprojects/vkdl.link/issues (ask for a private contact if the content is sensitive).
