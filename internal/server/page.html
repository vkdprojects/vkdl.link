Formatos e tamanhoFormats and size

Aceitamos PNG, JPEG, GIF e WebP de até {{.MaxUpload}}. Conferimos o conteúdo do arquivo, não só o nome: SVG, PDF e outros formatos são recusados.

We accept PNG, JPEG, GIF and WebP up to {{.MaxUpload}}. We check the file contents, not just the name: SVG, PDF and other formats are refused.

Por quanto tempo a imagem fica?How long does the image stay?

Envios sem conta são grátis e não têm prazo garantido. Quando o espaço acaba, as imagens mais antigas são apagadas primeiro para dar lugar às novas. Guarde uma cópia do que for importante.

Em breve: chaves de API com tempo de guarda garantido.

Uploads without an account are free and have no guaranteed retention. When space runs out, the oldest images are deleted first to make room. Keep a copy of anything important.

Coming soon: API keys with guaranteed retention.

Quem pode ver?Who can see it?

Qualquer pessoa que tiver o link. O site não lista nem divulga as imagens, mas o link não é uma senha: não envie nada que precise ficar em segredo.

Anyone who has the link. The site never lists or promotes images, but a link is not a password: don't upload anything that must stay secret.

PrivacidadePrivacy

Não guardamos o seu IP. Usamos só um código embaralhado (hash) dele para limitar abusos. A página não usa cookies, anúncios nem rastreadores.

We don't store your IP address, only a scrambled code (hash) of it to limit abuse. This page uses no cookies, ads or trackers.

Como apagar ou pedir remoçãoDeleting and removal requests

Depois do envio você recebe um link de exclusão: abra-o para apagar a imagem quando quiser. Perdeu o link, ou a imagem não é sua (LGPD, direitos autorais, abuso)? Abra uma issue no GitHub. Se o conteúdo for sensível, não cole o link lá: peça um contato privado.

After uploading you get a delete link: open it to delete the image whenever you want. Lost it, or the image isn't yours (privacy, copyright, abuse)? Open an issue on GitHub. If the content is sensitive, don't paste the link there: ask for a private contact.

A simple HTTP API, no sign-up, JSON responses. Errors look like {"error": "...", "message": "..."}.
